# VS Code Projects

A collection of project folders for SAP planning, Excel manipulation, and timesheet analysis.

## 📁 Projects

| Project | Description | Key Technology |
|---------|-------------|----------------|
| [apm-sap-plan](apm-sap-plan/) | SAP ECC → S/4HANA migration planning with Gantt charts & FTE tracking | Python, openpyxl |
| [excel improvement](excel%20improvement/) | Excel file manipulation scripts (charts, formulas, Gantt) | Python, openpyxl |
| [timesheet analysis](timesheet%20analysis/) | Timesheet data analysis and summarization | Python, openpyxl |

## 🚀 Quick Start

```bash
# Navigate to any project folder
cd apm-sap-plan

# View project-specific README
cat README.md

# Run scripts (see each project's README for details)
python build_gantt.py
```

## 📦 Dependencies

All projects require:
- Python 3.12+
- openpyxl

```bash
pip install openpyxl
```
